# dns-wan-transport

Легковесный мост на Go для интеграции локальных DNS-серверов с системным механизмом WAN Failover в роутерах Keenetic (через среду Entware).

## Суть проблемы и решение

Если вы используете локальный DNS-сервер на роутере (AdGuard Home, SmartDNS, Unbound), развернутый на USB-накопителе, сеть может сломаться при сбое флешки или сервиса. 

Данная утилита поднимает локальный SOCKS5-сервер, который Keenetic воспринимает как штатный WAN-интерфейс (Прокси-клиент).
- Пока локальный DNS работает, утилита удерживает SOCKS-соединение.
- Если DNS перестает отвечать, утилита закрывает порт, заставляя KeeneticOS мгновенно переключить интернет на резервный WAN-канал.

## Особенности

- Написан на Go: без тяжелых зависимостей.
- Низкое потребление ресурсов: оптимизирован под процессоры MIPS/ARM.
- Реальный DNS Health Check: делает UDP-запросы, а не просто проверяет порт.
- Поддержка нескольких бэкендов одновременно.
- Встроенный Web UI для мониторинга времени ответа (Latency).

## Компиляция

Для сборки используйте Makefile:
make mipsle  # Для большинства моделей (Viva, Giga, Extra, Air)
make arm     # Для флагманских моделей (Ultra, Peak)
